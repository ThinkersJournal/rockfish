# Third-party notices

## AMD HIP headers (`vendor/hip/`)

- **What:** 14 public HIP C++ header files, the include closure of `hip/hip_runtime_api.h` and `hip/hiprtc.h`, plus `hip/library_types.h` (`hipDataType`, added for hipBLASLt) (excluding `nvidia_detail`, and `amd_detail/hip_prof_str.h`, which is only included when `USE_PROF_API` is defined). - **Licence:** MIT. The text is `vendor/hip/LICENSE.md`, git blob `4d43ac8700191c7a688e99ca2a25685963a61bb2`, identical for `projects/hip/LICENSE.md` and `projects/clr/LICENSE.md` at that commit.
- **Verification:** every file is byte-identical to the upstream git blob. `vendor/hip/MANIFEST.tsv` lists, for each file, its upstream path and blob sha; `tools/verify-vendor.sh` recomputes each blob sha locally, and `tools/verify-vendor.sh --online` also reads the sha from GitHub at the pinned commit. `.gitattributes` marks `vendor/**` as `-text` so line-ending conversion cannot alter a copy.
