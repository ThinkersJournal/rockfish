# rockfish-hip-emit

The `Hip` backend: lowers Unpopped's neutral `KernelPlan` and kernel-layer `KernelFn` to HIP C++ source text. Text only: no ROCm and no GPU are needed to build or test, and the emitted source has not been through a HIP compiler (UNVERIFIED). Anything it cannot spell exactly is refused by name with a typed `UnsupportedKernel` error; see the workspace `README.md` and `docs/PATENT-SWEEP.md` in the repository for what is declined and why. Not published (`publish = false`). `Hip::lower_kernel_for` also lowers Unpopped's opaque-tile statements for three AMD matrix atoms (f32 and f64 `16x16x4` MFMA on gfx908/gfx90a/gfx942 as listed in `src/tile.rs`, f16 `16x16x16` WMMA on gfx1100-1103/1150-1153) as clang builtin calls over per-lane fragments; compiled by clang for the AMDGPU target in tests, never run on a device (UNMEASURED).
